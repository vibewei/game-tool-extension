游戏助手 · 设置

设置会自动保存到浏览器扩展存储，页面里的助手会实时生效。当前版本 -

自动开启插件

配置插件在哪些域名自动开启（页面加载后快捷键、自动录屏等功能生效）。其它域名默认不启用，可用扩展图标 / Alt+G 手动临时开启。

自动开始录屏（在已开启的页面）
关闭后需要手动点「开始录屏」或按快捷键
自动开启插件的域名
每行一个域名，支持通配符：*.m2time.net 会匹配它和所有子域名。
留空 = 所有页面自动开启；填写后，只有这些域名会自动启用插件（快捷键、自动录屏等），其它页面需要手动用扩展图标 / Alt+G 开启。

快捷键

点输入框后直接按组合键即可修改；按 Backspace 清空（取消该快捷键），按 Esc 取消编辑。修改后点下方「保存设置」。

快捷键在页面里生效；输入框聚焦时不会触发。

面板

收起后显示悬浮入口胶囊
关闭后隐藏面板时不再出现「游戏助手」小胶囊，可通过快捷键或扩展图标重新打开
紧凑模式
面板一次只展开一个区块，并隐藏辅助说明，减少占用面积
保存位置（选择目录）在页面面板的「录屏回放」区块里设置，因为目录授权绑定在当前页面。
