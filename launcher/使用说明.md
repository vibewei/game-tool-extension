# 游戏助手 · 分发给同事的版本

这个文件夹可以直接压缩后发到飞书群/共享盘，同事解压或直接双击即可使用。

## 一、同事怎么用（推荐：Edge，零安装）

1. 双击 **`启动游戏助手.bat`**
2. 会自动把最新插件同步到本机，并用一个独立的 Edge 配置打开游戏页面
3. 首次需要登录游戏账号（使用你的测试账号），之后会记住登录状态
4. 面板默认不显示，**按 `F8`、`Alt+G` 或点浏览器右上角扩展图标**打开

不需要安装扩展、不需要「加载已解压的扩展程序」、不需要重新加载。

## 二、以后怎么更新（维护者操作）

1. 把最新版 `game-tool-extension` 文件夹覆盖到本文件夹里的同名目录
2. 同事**下次双击「启动游戏助手.bat」时会自动同步最新版**，不需要任何操作

> 如果你们把版本放到了 Gitee / GitHub / 内网服务器，也可以直接用「检查更新」自动拉取（见第七节），不用再手动更新共享文件夹。

如果把这个文件夹放在共享盘上，效果最好：

- 整个 `game-tool-launcher` 放共享盘（或飞书同步目录）
- 每人桌面快捷方式指向共享盘里的 `启动游戏助手.bat`
- 你只更新共享盘里的 `game-tool-extension`，大家下次启动自动用新版
- 注意：不要把启动器各自复制到本地，否则收不到共享盘的更新；如果必须本地使用，把 `config.json` 里的 `sourceDir` 指向共享盘目录即可

## 三、必须用 Chrome 的同事

Chrome 137+ 不支持命令行自动加载扩展，所以 Chrome 下需要每人**首次手动加载一次**：

1. 双击 **`首次安装到Chrome.bat`**，按提示在 `chrome://extensions` 里开启开发者模式 → 加载已解压 → 选择 `%LOCALAPPDATA%\GameToolExtension`
2. 首次加载后，以后更新只需双击 **`更新并重启Chrome.bat`**：会自动同步最新插件并重启 Chrome（会恢复标签页）
3. 不需要再解压/重新加载

## 四、正式给全公司推广的话

| 方式 | 更新体验 | 需要什么 |
| --- | --- | --- |
| Chrome 应用商店（不公开/unlisted） | 自动更新 | 开发者账号、审核；建议去掉 `debugger` 权限提高通过率 |
| 公司企业策略托管 | 自动更新，全员无感 | IT 在内网放 CRX + update URL，配置 ExtensionInstallForcelist |
| Edge 加载项商店 | 自动更新 | 仅适用于同事都用 Edge 的情况 |
| 本启动器方案 | 双击即更新（Edge），Chrome 双击更新并重启 | 无需商店/管理员权限，适合测试组临时使用 |

## 五、配置文件

`config.json`：

| 字段 | 说明 |
| --- | --- |
| `gameUrl` | 启动后打开的游戏地址 |
| `sourceDir` | 插件更新源目录（共享盘路径）；留空表示使用本文件夹里的 `game-tool-extension` |
| `localExtensionDir` | 插件同步到本机的固定目录，默认 `%LOCALAPPDATA%\GameToolExtension` |
| `edgeProfileDir` | Edge 独立配置目录，默认 `%LOCALAPPDATA%\GameToolEdgeProfile` |
| `edgePath` / `chromePath` | 浏览器路径，留空自动查找 |
| `update.versionUrl` | 代码仓库里 `version.json` 的地址（填了才启用“检查更新”） |
| `update.zipUrl` | 新版插件 zip 的下载地址；留空时使用 `version.json` 里的 `zipUrl` |
| `update.pageUrl` | 版本发布页，选填 |
| `update.autoCheck` | 设为 `true` 时每次启动前自动检查代码仓库 |

## 七、代码仓库自动更新（可选）

适合把插件版本放到 Gitee / GitHub / 公司内网 HTTP 服务器。

**1. 仓库里放两个文件**

```
repo/
  version.json
  game-tool-extension.zip
```

`version.json`：

```json
{
  "version": "1.3.4",
  "zipUrl": "https://gitee.com/你的账号/仓库/releases/download/v1.3.4/game-tool-extension.zip",
  "pageUrl": "https://gitee.com/你的账号/仓库/releases"
}
```

`game-tool-extension.zip` 就是插件文件夹的压缩包（和 `game-tool-extension.zip` 结构一致）。

**网络场景快捷键**：面板里可直接点 9 个场景按钮，也可以按 `Alt+Shift+1~8` 快速切换（`Alt+Shift+1` 正常 … `Alt+Shift+8` 断网10s）；收起后的小胶囊可点右侧 × 隐藏。

**2. 在 `config.json` 里填写地址**

```json
"update": {
  "versionUrl": "https://gitee.com/你的账号/仓库/raw/master/version.json",
  "zipUrl": "https://gitee.com/你的账号/仓库/releases/download/v1.3.4/game-tool-extension.zip",
  "pageUrl": "https://gitee.com/你的账号/仓库/releases",
  "autoCheck": false
}
```

常见地址：

- Gitee 原始文件：`https://gitee.com/用户名/仓库/raw/分支/version.json`
- GitHub 原始文件：`https://raw.githubusercontent.com/用户名/仓库/分支/version.json`

**3. 使用方式**

- 手动：双击 **`检查更新.bat`** → 查询仓库 `version.json` → 有新版自动下载并覆盖本机插件 → 重新打开游戏
- 自动：把 `update.autoCheck` 改成 `true`，每次双击「启动游戏助手.bat」都会先查仓库再启动

**4. 注意事项**

- `versionUrl` 返回 JSON 或纯版本号文本都可以；版本号建议用 `1.3.4` 这种格式
- 私有仓库需要 token，当前脚本不支持；请用公开仓库或公司内网 HTTP 地址
- 脚本默认直连、不走系统代理（避免公司代理导致内网/localhost 超时）
- Chrome 用户更新后双击「更新并重启Chrome.bat」即可

## 八、面板里的「检查更新」按钮

插件面板底部有「检查更新」按钮，点击会读取本仓库的 `version.json`：

- 已是最新：显示当前版本
- 发现新版本：提示版本号，并出现「打开更新页」按钮
- 自动安装仍需使用启动器（双击 `检查更新.bat`），或在 Chrome 里用新包覆盖后重新加载扩展

## 九、常见问题

- **Edge 首次打开提示选择配置/登录**：属正常，独立配置第一次需要登录，之后不用
- **更新后还是旧版**：确认共享盘里的 `game-tool-extension` 已覆盖为新版；双击启动器时会打印「插件版本：本地 = x，最新 = y」
- **Chrome 更新脚本提示找不到 Chrome**：在 `config.json` 里填写 `chromePath`
